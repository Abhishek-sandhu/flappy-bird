# 🎮 Deluxe Flappy Bird

A modern, enhanced version of the classic **Flappy Bird** game, built with vanilla **HTML**, **CSS**, and **JavaScript**.

## 🚀 Features

✨ **Smooth Gameplay** - Realistic gravity and jump mechanics for an engaging experience  
🌟 **Dynamic Pipes** - Procedurally generated pipe obstacles with increasing difficulty  
🏆 **Score System** - Real-time score tracking with persistent high score storage  
🎶 **Audio Effects and Music** - Jump sounds, point sounds, crash sounds, and background music  
💫 **Visual Effects** - Particle effects on jumps, bird shadows, and animated background  
☀️🌙 **Day-Night Cycle** - Experience the game in a dynamic time environment  
📱 **Responsive Design** - Adapts to different screen sizes for desktop and mobile gaming  
🌐 **Cross-Platform** - Play seamlessly on your browser, desktop, or mobile devices  

---

## 🕹️ How to Play

1. **Start the Game**: Click or tap the screen to begin.  
2. **Flap the Bird**: Tap, click, or press the **spacebar** to make the bird jump.  
3. **Avoid Obstacles**: Navigate through the gaps in the pipes without hitting them or the ground.  
4. **Score Points**: Earn points for every pipe passed successfully.  
5. **Challenge Yourself**: Be prepared for increasing difficulty as you score higher.

## 🛠️ Installation & Setup

### **Option 1**: Play Directly in Your Browser  
1. Clone or download this repository.  
2. Open the `index.html` file in your web browser.  
3. Start playing instantly!

### **Option 2**: Run on a Local Server *(Recommended for Full Features)*  
1. Clone the repository using Git:  
   ```bash
   git clone https://github.com/Abhishek-sandhu/flappy-bird.git
   ```
2. Navigate into the project directory:  
   ```bash
   cd flappy-bird
   ```
3. Start a local server:  
   For example, using Python:  
   ```bash
   python -m http.server
   ```
4. Open your browser and go to:  
   `http://localhost:8000` *(or the port your server is using)*

## ⚙️ Game Mechanics

- **Gravity** - Feel the challenge of constant downward acceleration.  
- **Jump Strength** - Control your bird with a fixed upward velocity.  
- **Dynamic Pipe Generation** - Face random gap heights with consistent widths.  
- **Collision Detection** - Watch out for precise hit detection with pipes and boundaries!  
- **Difficulty Scaling** - The bird won't be the only one soaring; pipe speed ramps up every 10 points.

## 🎨 Game Customization

Easily tweak **Deluxe Flappy Bird** to make it your own!  

- Adjust **gravity**, **jump strength**, and **pipe speed** in the `script.js` file.  
- Modify **colors**, **animations**, or **design** in the `styles.css` file.  
- Add new **sound effects** or change the existing ones in the `audio` folder.
